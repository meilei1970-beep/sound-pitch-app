# 聲音高低與調音器 v2

## 新功能
- 重新設計、簡化 iPad 介面
- 「測量音高」與「樂器調音」兩種模式
- 調音時顯示：太低、音準了、太高
- 顯示最接近音名、唱名、目前頻率與目標頻率
- 可選 A4 = 438 / 440 / 442 Hz
- 音訊只在裝置內即時分析，不會上傳或儲存錄音

## 更新 GitHub Pages
1. 進入原本的 sound-pitch-app repository。
2. 點 Add file → Upload files。
3. 把本資料夾的所有檔案拖入。
4. 系統詢問同名檔案時，直接覆蓋。
5. 按 Commit changes。
6. 等待約 1–3 分鐘後重新整理網站。
7. 若仍顯示舊版，可重新整理，或在 iPad Safari 關閉頁面後重新開啟。

## 使用建議
調音模式最適合卡林巴琴、鐵琴、直笛、吸管笛等單一且持續的音。人聲、拍手與教室噪音會包含較多頻率，因此可能跳動。
