# 聲音高低與調音器 v3

## 新增：指定目標音
調音器現在有兩種方式：

1. 自動辨識
   - 自動找出最接近的音。
   - 適合自由測試不同音。

2. 指定目標音
   - 可從 C3 到 C6 選擇音名。
   - 系統只依照選定的目標音判斷太低、準確或太高。
   - 適合逐音調整卡林巴琴、鐵琴、直笛與吸管笛。

## 更新 GitHub Pages
1. 進入原本的 sound-pitch-app repository。

4. 按 Commit changes。
5. 等 GitHub Pages 最新部署變成綠色勾勾。
6. 若仍顯示舊版，使用 Ctrl + Shift + R，或在網址後加 ?v=3。
