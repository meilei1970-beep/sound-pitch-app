# 聲音高低測量器

適合 iPad Safari 使用的簡易網頁 App。

## 學生使用方式
1. 用 Safari 開啟網站。
2. 按「開始測量」。
3. 第一次使用時，允許網站使用麥克風。
4. 靠近樂器，發出單一且持續的聲音。
5. 查看頻率、音名、低／中／高音，以及最高、最低、平均值。

## 發布到 GitHub Pages
1. 建立一個新的 GitHub repository。
2. 把資料夾內所有檔案上傳到 repository 根目錄。
3. 進入 Settings → Pages。
4. Source 選 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，按 Save。
6. GitHub 會產生 HTTPS 網址，可貼到 Google Classroom 或製作 QR Code。

## iPad 加到主畫面
Safari 開啟網站 → 分享按鈕 →「加入主畫面」。

## 注意
- 麥克風功能必須在 HTTPS 網站或本機環境使用。
- 最適合單一、穩定音源，例如鐵琴、卡林巴琴、直笛或吸管笛。
- 教室環境太吵、人聲或拍手等複雜聲音，頻率可能跳動。
- 音訊只在裝置內即時分析，本程式不會上傳或儲存錄音。
